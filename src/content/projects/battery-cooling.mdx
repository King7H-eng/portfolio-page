## About this project

A final-year BEng capstone dissertation, continuing the work of a previous student. It is a computational study of a new type of passive cooling for batteries, using metal-organic frameworks (MOFs) for adsorption cooling.

The project includes a literature review of the current state of battery thermal management technologies. It then involved building a model of a MOF-coated battery cell, validating it against experimental results, and scaling it up to model multiple cells in an air-cooled battery pack. Finally, it included the optimisation of a proposed design for a hybrid battery thermal management system (BTMS).

Supervised by Dr Zhiwei Ma. Builds on Lukas Koehne-Mitchell's original experimental study.
